# Foreword: Why This Moment Changes Everything

Every platform shift gets announced before it arrives. The web was "publishing
for everyone" for years before a business could actually run on it. Cloud was
"someone else's computer" until it became the default place to put a company.
Agents are in that gap right now: the demo is impressive, the install is one
command, and the failure rate on real work is still high enough that most
operators quietly go back to doing it themselves.

What changed is not that a model got smarter. What changed is that the agent
stopped being a chat window and became a workstation. It has a filesystem. It has
a browser. It has a terminal. It has credentials you grant deliberately. It runs
on a schedule without being prompted. It hands work to another agent and comes
back with a result. That is not a better chatbot. That is a junior operator with
an unusually short memory and an unusually high tolerance for boring work.

The businesses that win the next two years will not be the ones with the cleverest
prompts. They will be the ones that took three expensive, repetitive jobs, wrote
down what "done" means, put a fence around the parts that touch money and
customers, and let software hold the line at 2 a.m.

That is a build problem, not a vision problem. This book is a build manual for it.
