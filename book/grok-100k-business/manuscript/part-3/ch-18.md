# Finance Agent — Track Money, Generate Reports, Catch Weirdness Early

**Premise.** The highest-value agent and the one that must never act alone.

## Beats

1. Read-only by default: categorize, reconcile, flag, report. Writes are notes, never amounts.
2. The monthly close checklist as an executable procedure with a completion hash.
3. Anomaly rules that catch real problems: duplicate vendor, amount drift, date gaps, missing invoice.
4. Reconciliation against a second source; when the two disagree, the agent stops and escalates.
5. Reporting: a one-page variance memo with the three numbers that matter.
6. The approval matrix for money: thresholds, dual control, and a tested revocation path.
7. Audit trail: every number in the report traceable to a row in a source file.

## What to measure

- Cross-artifact verification catches what single-file checks miss: a position without a product, a price with no asset.

## Do not

- Never grant payment initiation. Never let the agent edit amounts. Not negotiable.
