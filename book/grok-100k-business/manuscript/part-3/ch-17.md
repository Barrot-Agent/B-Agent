# Operations Agent — Keep the Business Running Without Constant Supervision

**Premise.** Ops is the best first agent: high frequency, clear rules, immediately measurable.

## Beats

1. The recurring queue: what happens daily, weekly, monthly, and who notices when it doesn't.
2. State machines over prompts: a task's status lives in a record, not in a chat.
3. Idempotency: every job can run twice without duplicating side effects.
4. Escalation ladder: retry → fallback → human, with a timer and a named owner.
5. Heartbeat: a dead-man's switch that fires when the agent does not run.
6. The exception queue: one inbox, sorted by blast radius, reviewed on a schedule.

## What to measure

- A run that silently stops is worse than a run that fails loudly; measure time-to-detect.

## Do not

- Do not build a queue nobody drains. An exception list with 400 items is a data loss incident.
