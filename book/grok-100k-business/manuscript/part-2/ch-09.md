# Skills — Encode Your Company's Best Employees Once

**Premise.** A prompt is a sentence. A skill is a procedure with a definition of done.

## Beats

1. Documented behaviour: show a Bot a task once, it can save the steps as a skill and rerun them on a schedule.
2. The skill schema that works: inputs, steps, tools, decision points, output format, done-when, escalate-when.
3. Versioning: skills are code. They get a repo, a diff and a regression sample.
4. The regression sample: ten inputs and ten expected outputs, re-run after every edit.
5. Routines: cadence, timezone, idempotency; what happens if a run overlaps the previous one.
6. Anti-pattern: a 2,000-word prompt with no examples and no failure path.

## What to measure

- Target: a new operator can run the skill from the file alone, without asking you anything.

## Do not

- Do not promise that an unwritten procedure can be inferred reliably from one demonstration.
