# MCP — Give Your Agent Keys to Systems That Matter

**Premise.** Connectors are where trust is spent. Grant the minimum, log every call.

## Beats

1. Documented: Grok Bot supports custom tooling over any MCP server or API; Grok Build discovers MCP servers via `grok inspect`.
2. The connector inventory: read-only first, write second, destructive never without approval.
3. Credential scoping: per-agent tokens, least privilege, rotation, and a revocation path you have actually tested.
4. Cost per call is a design parameter: web search $5/1k, code execution $5/1k, collections $2.50/1k.
5. Failure handling: timeout, 429, auth expiry; retry with jitter, escalate after N.
6. The audit question: can you answer 'what did this agent read and write last Tuesday' from logs alone?

## What to measure

- Eight relevant records beat eighty: retrieval precision is a cost lever, not a nicety.

## Do not

- Do not claim an integration exists. Verify the MCP server name and tool list first.
