# Data, Memory & Long-Term Context — Stop Making Agents Forget

**Premise.** Memory is a schema problem before it is a model problem.

## Beats

1. Three memories: identity (who the customer is), procedure (how we do things), run state (this job).
2. Files as the default store; a database only when you need queries over thousands of records.
3. Retrieval discipline: recency, relevance, and an explicit authority order when facts conflict.
4. Expiry: prices, policies and contacts decay; stale memory is worse than no memory.
5. Context budget: what goes in the prompt every run, what is fetched on demand.
6. The correction log: every human fix is written back, or the same error repeats.

## What to measure

- Measure repeat-error rate: the same mistake twice means memory was not updated.

## Do not

- Do not claim the agent 'learns' from conversation alone. It learns when you write it down.
