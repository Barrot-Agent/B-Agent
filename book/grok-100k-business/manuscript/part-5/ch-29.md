# Cost Optimization — Never Burn Model Calls Where Code Can Solve

**Premise.** The cheapest call is the one you replaced with a regex.

## Beats

1. Cost anatomy: input tokens, output tokens, tools, retries, context re-sends.
2. Deterministic first: parsing, arithmetic, formatting, routing and dedupe belong in code.
3. Prompt caching and stable prefixes; what to keep out of the variable part.
4. Batch API for anything that can wait 24 hours (20% off on the text models listed).
5. Context hygiene: summarize intermediate state instead of re-sending transcripts.
6. Model routing: cheap model for extraction, strong model for judgment; measure the quality delta.

## What to measure

- A 12K/2K run costs $0.036; ten retries turn it into $0.36 — retry policy is a cost lever.

## Do not

- Do not optimize tokens while ignoring tool calls; searches usually dominate.
