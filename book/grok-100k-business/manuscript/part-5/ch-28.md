# Monitoring & Evaluation — Catch Failures Before Customers Do

**Premise.** If the model grades its own homework, the grade is a feeling.

## Beats

1. Three layers: liveness (did it run), correctness (is the output right), consistency (do artifacts agree).
2. Mechanical checks first: schema, arithmetic, dates, required fields, cross-file agreement.
3. The cross-artifact verifier: read the live state and assert internal consistency, not just per-file validity.
4. Sampled human review with a rubric; log the sample so coverage is provable.
5. Regression suites for skills: the ten-item golden set, run on every change.
6. Alert design: what pages a human, what waits for the weekly review, and what is noise you delete.

## What to measure

- A real verifier found: position without product, confidence 0.0 published, signal 18 days stale, product missing, below-chance accuracy.

## Do not

- Do not use another LLM as the only judge. Independent code checks first.
