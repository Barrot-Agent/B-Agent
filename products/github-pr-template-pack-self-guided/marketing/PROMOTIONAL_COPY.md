dollar amount in the parsed text. The other 94 did not, which is not proof they
were unpaid. A label is not an offer, and a stated amount is not escrow.

So the pack I built starts before the editor:

   seen, and the acceptance criteria.

   reason on every rejection.
3. A 120-minute phase gate that reports `CLAIM BROKEN` when the run goes over.
4. A PR builder and evidence pack that reject placeholders and claims without
   evidence.

It ships six templates, four Python modules, 76 tests, and generated examples.
It does not find bounties or promise payment.

## Do not write

- "Guaranteed", "risk-free", "passive income", "easy money"
- "Make $X per week"
- "Works for any issue"
- "The only guide you need"
- A testimonial that was not given by a real buyer
- A countdown or "only N copies"

Any of these in a draft is a reason to stop and rewrite.
