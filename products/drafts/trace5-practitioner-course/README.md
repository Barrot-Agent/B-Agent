# TRACE-5 Practitioner Course - DRAFT

Status: DRAFT. Not published. Awaiting approval.

## Problem

Teams are asked to prove that an AI feature's claims are grounded. Most cannot show
where a quote came from, or whether the source still exists. This course teaches the
five checks and the three grades, with exercises that fail loudly when done wrong.

## Outline

1. Setup: a claims file, a CLI, and a first failing validation
2. Module 1: quote existence and why paraphrase fails
3. Module 2: source metadata, DOI, and retraction state
4. Module 3: independence between sources
5. Module 4: verdict letters, falsifiers, upgrade conditions
6. Module 5: wiring the checks into CI so they cannot be skipped
7. Capstone: audit an unfamiliar claims file, defend each grade

Each module: a 6-minute script, one exercise, one quiz question, and a passing and a
failing example. The capstone is graded against a rubric with three bands.
