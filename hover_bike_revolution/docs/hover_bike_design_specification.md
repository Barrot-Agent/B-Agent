# Hover Bike Design Specification — Barrot HoverBike MK-I

## Overview

The Barrot HoverBike MK-I is a fully 3D-printable, open-source magnetic levitation bicycle designed for the maker community. It uses passive Halbach array magnetic levitation over a conducting aluminium track, combined with active coil stabilisation, BLDC hub-motor propulsion, and a LiFePO4 + solar + regenerative hybrid power system.

## Physics Principles

### Passive Halbach Levitation

A Halbach array arranges permanent magnets so that the magnetic flux is concentrated on one side while nearly cancelling on the other. When the array moves over a conducting track (aluminium plate), eddy currents are induced in the track. These currents create a repulsive force that levitates the array.

Key equation (lift force per unit area):

```
L = (B₀² / 2μ₀) × (v/vₓ) / √(1 + (v/vₓ)²)
```

Where:
- `B₀` = peak surface field of the array (T)
- `μ₀` = vacuum permeability (4π×10⁻⁷ H/m)
- `v` = translational speed (m/s)
- `vₓ` = characteristic velocity = ρ×k/μ₀ (depends on track resistivity ρ and wavenumber k)

**Minimum levitation speed** ≈ 18 km/h for the specified array and aluminium track.  
Below this speed, the **active stabilisation coils** carry the full load.

### Active Stabilisation

Hall effect sensors measure the magnetic field gap. A PID controller adjusts current through correction coils to maintain the target gap (150 mm nominal) against disturbances. Power: 50–100 W steady-state.

## Safety Considerations

1. Halbach magnet forces exceed 500 N — crush hazard during assembly.
2. LiFePO4 cells must be handled by trained builders only.
3. Maximum tested operating speed: 50 km/h. Exceeding this is untested.
4. The bike is not waterproof — avoid rain and puddles.
5. Riding on standard road surfaces requires the active stabilisation to carry full levitation weight (higher power consumption).
6. Dedicated aluminium or copper track surface (6 mm thick) achieves the best performance.
