# Optional heavy integrations for B-Agent.
# The core package (requirements.txt) deliberately stays dep-light; these are
# required only by the modules listed below and can be installed on demand:
#   pip install -r requirements-integrations.txt
#
# barrot_agent/orchestration/deploy_databricks.py        -> databricks-sdk
# barrot_agent/orchestration/deploy_huggingface.py       -> huggingface_hub
# barrot_agent/orchestration/inference_node.py           -> flask
# barrot_agent/tools/kaggle_competitions_automation.py   -> kaggle, pandas, scikit-learn
# barrot_agent/trading/coinbase_trader.py                -> cdp-sdk (imports as `coinbase`)
#
# PLATFORM NOTES (verified 2026-11-14 on aarch64 Termux/Debian hybrid):
# - The versions below are pinned to the newest releases whose dependency
#   trees need NO Rust compiler (hf-xet, rpds-py, cryptography all require
#   Rust when built from source).
# - On Debian-class systems prefer the distro packages for the native deps:
#     apt-get install python3-cryptography python3-pandas python3-sklearn
#   then pip-install the rest (verified working combination).
# - kaggle_competitions_automation imports cleanly WITHOUT credentials now;
#   the credential error is deferred to _build_api() call time.
