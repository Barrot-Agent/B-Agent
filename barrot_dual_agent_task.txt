BARROT TASK — DUAL-AGENT DELIBERATION

Implement the Barrot V3 Dual-Agent Deliberation layer directly in this repository.

GOAL

Create an evidence-backed communication protocol between Barrett and ChatGPT so both can independently examine the same repository evidence, record separate analyses, exchange them, identify agreement/disagreement, and never treat agent agreement itself as verification.

Integrate with the EXISTING Barrot architecture.
Do NOT create a parallel state, evidence, research, or completion architecture.

REQUIRED

1. SHARED EVIDENCE PACKET

Include:
- case/task ID
- repository identity
- branch/ref
- commit SHA
- working-tree fingerprint
- relevant files
- relevant diffs
- commands/results
- tests
- failures
- artifacts
- timestamps
- provenance

2. INDEPENDENT REPORTS

Maintain separate BARRETT and CHATGPT reports.

Each report contains:
- observations
- evidence references
- interpretation
- proposed action
- risks
- objections
- unresolved questions
- status/confidence

Never overwrite one agent's report with the other.

3. DELIBERATION RECORD

Persist:
- evidence
- both reports
- agreements
- disagreements
- disputed claims
- required evidence
- proposed resolution
- validation evidence
- final decision
- provenance

4. DISAGREEMENT GATE

Material disagreement must produce:

DISPUTED

Do not automatically execute the disputed action.

5. AGREEMENT IS NOT VERIFICATION

Even when both agents agree, deterministic repository validation is still required.

6. PRESERVE EXISTING SAFETY

Do not bypass:
- tool allowlists
- path restrictions
- security gates
- human authority gates
- validation gates
- completion gates
- checkpoints
- provenance
- deterministic fingerprints

7. PERSISTENCE AND RESUME

A deliberation must survive interruption and resume from persisted state.

8. ANTI-CIRCULARITY

Barrett repeating ChatGPT's conclusion, or ChatGPT repeating Barrett's conclusion, must not qualify as independent analysis.

Each report must reference independently observed evidence.

9. CHATGPT BRIDGE

Implement provider-neutral JSON import/export for ChatGPT deliberation packets.

Do NOT require an OpenAI API or paid service.

Local file exchange must work.
