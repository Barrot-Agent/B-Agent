# Barrot V3 Source Set 01 — acquisition catalog

This catalog records the ten external references supplied in Source Set 01. The supplied bundle contains metadata summaries and official source locations; it does **not** contain the full authoritative standards/specifications.

All entries therefore begin with `catalogued_not_acquired`. This is deliberate: listing a URL or storing a summary is not evidence that Barrot acquired, parsed, decomposed, corroborated, or ingested the underlying source.

Use the canonical MMI execution and evidence-ledger path for future acquisition. Record the exact acquired artifact hash, publisher/version, acquisition time, parser version, scope, component/provenance depth, observations, interpretations, contradictions, gaps, and verification outcome. Do not mark an entry acquired until the actual artifact and its MMI evidence exist.

External references remain subordinate to Barrot's mission, repository-verified implementation facts, MMI contract, and explicit governance boundaries.
